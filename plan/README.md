# plan/

Text planning docs live here (Hallie's call, 2026-08-14).

A doc in this directory serves as a **stand-in**. Once its content lands in the live graph
(Penelope gen4-api, `:8014`), the graph holds the plan of record and the doc becomes a
reading of it — kept honest against the graph, or deleted. A planning doc that has drifted
from the graph does more harm than no doc, for exactly the reason the `penelope-planning`
skill needed a rewrite: it went on reading as current for three app versions after it
stopped being true.
